# US10 settings, preferences, shortcuts and audio

Date: 2026-10-17. Scope: core Settings milestone source. Partial; SC-014 is not claimed.

## Implemented

- Typed preferences in `src/desktop/preferences.rs`: appearance, board aid toggles, audio (70% master, 100% category levels, multiplicative gain), shortcut overrides, typed patches, explicit revision, and a draft separating saved from pending values.
- Versioned 1 MiB JSON codec, import preview/confirm/apply and reset preview/confirm/apply in `src/desktop/preferences_import.rs` and `src/desktop/preferences_reset.rs`. Exports contain no machine paths; unsupported versions are rejected unchanged.
- Compare-and-set preferences repository on Diesel in `src/storage/preferences_repository.rs`, served by the document actor.
- Workspace action registry, palette, shortcut resolution, reserved/conflict checks and shortcut/audio settings helpers under `src/presentation/action` and `src/presentation/settings`.
- Audio router (priority, 100 ms coalescing, overlap dropping, discard when muted or unfocused), native audio port with warning-only failure, aggregate focus tracking and per-side low-time-used flags.
- Original WAV cues and manifest generated by `chess-tools sounds-generate`.
