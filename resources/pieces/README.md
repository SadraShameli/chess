# Original sculpted piece library

`chess.glb` is a self-contained glTF 2.0 library generated by
[`generate-pieces.ts`](../../ui/tools/generate-pieces.ts). The generator uses
Three.js geometry, a constructive subtraction for the bishop's diagonal slit,
and glTF-Transform's standard binary serializer. It needs no browser globals,
downloaded artwork, textures, decoders or runtime network requests.

Run `bun run pieces:generate` from `ui` after changing the sculpture source.
`bun run pieces:check`, included in the frontend lint gate, regenerates in memory
and checks both committed files byte for byte. The provenance records source and
GLB SHA-256 digests, exact authoring dependencies, dimensions, triangle counts,
materials and ownership. Stable dependency pins and the Bun lockfile own the
reproducible authoring environment.

Clone a named parent object from the loaded scene. Names use `white_` or `black_`
followed by `pawn`, `knight`, `bishop`, `rook`, `queen` or `king`. Each parent
contains one mesh. All library objects intentionally overlap at the origin;
place clones in the board scene instead of displaying the entire library.
Geometry buffers are shared across the two color variants. Loaded clones also
share geometry and materials, so dispose those resources at library teardown.

Coordinates use Y up and one unit per square. The base is centered at x=0,z=0,
with its underside at y=0. The knight faces local -Z. The largest base diameter
is 0.66 units and the king is below 1.21 units high. Ivory `#f2e6cb` and ebony
`#202328` use opaque nonmetallic PBR materials with a satin roughness. The
renderer supplies illumination and shadows.

Browser tests load the checked-in GLB with the actual Three.js loader and check
all twelve objects, geometry, materials and dimension bounds. These checks do
not establish premium readability at every camera position or compatibility
with the supported native WebViews; those remain visual and release acceptance
work under the [presentation contract](../../specs/001-reckless-desktop-chess/contracts/ui-experience.md).
